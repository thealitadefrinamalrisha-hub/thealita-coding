# Analisis Web Belanja Online

## 1. Pengertian

Web belanja online adalah platform e-commerce yang memungkinkan pengguna membeli produk melalui internet tanpa datang langsung ke toko.

Contoh platform:

* Tokopedia
* Shopee
* Lazada
* Bukalapak

---

# 2. Tujuan Sistem

Tujuan utama web belanja online:

* Mempermudah transaksi jual beli
* Menjangkau pelanggan lebih luas
* Menghemat waktu dan biaya
* Mendukung pembayaran digital
* Meningkatkan penjualan bisnis

---

# 3. Analisis Kebutuhan Sistem

## A. Kebutuhan Pengguna

### Pembeli

* Registrasi akun
* Login
* Melihat produk
* Mencari barang
* Menambahkan ke keranjang
* Checkout
* Pembayaran online
* Tracking pesanan

### Penjual/Admin

* Mengelola produk
* Mengelola stok
* Mengelola pesanan
* Melihat laporan penjualan

---

# 4. Analisis Fitur Utama

| Fitur             | Fungsi                     |
| ----------------- | -------------------------- |
| Login/Register    | Identitas pengguna         |
| Katalog Produk    | Menampilkan barang         |
| Search & Filter   | Mempermudah pencarian      |
| Keranjang Belanja | Menyimpan produk sementara |
| Checkout          | Konfirmasi pembelian       |
| Payment Gateway   | Pembayaran online          |
| Tracking Order    | Memantau pengiriman        |
| Wishlist          | Menyimpan produk favorit   |
| Review & Rating   | Penilaian produk           |

---

# 5. Analisis UI/UX

## UI yang Baik

✅ Tampilan bersih
✅ Navigasi mudah
✅ Foto produk jelas
✅ Responsive mobile
✅ Checkout cepat

## Masalah yang Sering Terjadi

❌ Website lambat
❌ Iklan terlalu banyak
❌ Checkout rumit
❌ Produk sulit dicari

## Rekomendasi

* Gunakan desain minimalis
* Optimalkan loading
* Gunakan kategori jelas
* Sediakan dark mode

# 10. Analisis SWOT

## Strength (Kekuatan)

* Praktis
* Bisa belanja 24 jam
* Banyak pilihan produk

## Weakness (Kelemahan)

* Risiko penipuan
* Ketergantungan internet
* Barang tidak bisa dicek langsung

## Opportunity (Peluang)

* Pengguna internet meningkat
* Cashless berkembang
* UMKM go digital

## Threat (Ancaman)

* Persaingan tinggi
* Cyber attack
* Perang harga
