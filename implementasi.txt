# Implementasi Web Belanja Online

Implementasi web belanja online adalah proses membangun sistem e-commerce dari tahap desain hingga menjadi aplikasi yang dapat digunakan oleh pelanggan dan admin.

---

# 1. Arsitektur Sistem

## Struktur Sistem

```text id="6jk4r7"
User Browser / Mobile
          ↓
Frontend Website
          ↓
Backend Server
          ↓
Database
          ↓
Payment Gateway & Shipping API
```

---

# 3. Implementasi Database

# A. Tabel Users

```sql id="m4v4m8"
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nama VARCHAR(100),
    email VARCHAR(100),
    password VARCHAR(255),
    role VARCHAR(20)
);
```

---

# B. Tabel Produk

```sql id="w6g59w"
CREATE TABLE produk (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nama_produk VARCHAR(100),
    harga INT,
    stok INT,
    gambar VARCHAR(255),
    deskripsi TEXT
);
```

---

# C. Tabel Cart

```sql id="ef6myj"
CREATE TABLE cart (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT,
    produk_id INT,
    qty INT
);
```

---

# D. Tabel Orders

```sql id="vfjix2"
CREATE TABLE orders (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT,
    total_harga INT,
    status VARCHAR(50),
    created_at TIMESTAMP
);
```

---

# E. Tabel Detail Orders

```sql id="4v20od"
CREATE TABLE order_detail (
    id INT AUTO_INCREMENT PRIMARY KEY,
    order_id INT,
    produk_id INT,
    qty INT,
    subtotal INT
);
```
